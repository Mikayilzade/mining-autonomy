## Apify Store monetized Actors
- Monetize your Actor: https://docs.apify.com/actors/publishing/monetize
- Pay-per-event pricing: https://docs.apify.com/actors/publishing/monetize/pay-per-event
- Pricing/costs: https://docs.apify.com/actors/publishing/monetize/pricing-and-costs
- Store publishing terms: https://docs.apify.com/legal/store-publishing-terms-and-conditions
- Monthly payouts / verification: https://docs.apify.com/actors/publishing/monetize/monthly-payouts
- Store pricing models: https://docs.apify.com/actors/running/actors-in-store

Established:
- Developers may publish and monetize automation/scraping/AI Actors.
- PPE can charge programmatic events such as result generation, item processing or an external API call.
- Current documented PPE profit formula is `(0.8 * revenue) - platform costs` when creator bears platform costs.
- Publishing terms state 80% creator share for rental/PPR/PPE fees, with platform costs potentially deducted.
- Payouts require billing details, payment method and identity verification.
- Current minimum payout thresholds documented as $20 PayPal/Wise and $100 other methods.

## RapidAPI provider marketplace
- Monetizing API: https://docs.rapidapi.com/do/docs/monetizing-your-api-on-rapidapicom
- Payouts and finance: https://docs.rapidapi.com/v2.0/docs/payouts-and-finance
- API provider page: https://get.rapidapi.com/api-provider/

Established:
- Provider can use pay-per-use, freemium and paid recurring plans, with overages.
- Current official payout docs state a flat 20% marketplace fee on Hub payments.

## GitHub Marketplace Apps
- Selling apps: https://docs.github.com/en/apps/github-marketplace/selling-your-app-on-github-marketplace
- Pricing plans: https://docs.github.com/en/apps/github-marketplace/selling-your-app-on-github-marketplace/pricing-plans-for-github-marketplace-apps
- Receiving payment: https://docs.github.com/en/apps/github-marketplace/selling-your-app-on-github-marketplace/receiving-payment-for-app-purchases
- Marketplace overview: https://docs.github.com/en/apps/github-marketplace/github-marketplace-overview/about-github-marketplace-for-apps

Established:
- Paid Apps support flat-rate or per-unit plans, monthly/yearly.
- Paid plans require organization ownership, publisher verification and financial onboarding.
- Current docs state GitHub retains 5% of transaction income for transactions after Jan 1, 2021.
- Current payment docs state electronic payment once monthly revenue reaches $500, paid at end of following month.

## AWS Marketplace SaaS

## Hugging Face Inference Providers
- Overview: https://huggingface.co/docs/inference-providers/en/index
- Pricing/billing: https://huggingface.co/docs/inference-providers/en/pricing
- Register as provider: https://huggingface.co/docs/inference-providers/en/register-as-a-provider

Established:
- HF routes inference requests across registered providers.
- Current docs say routed users pay provider standard rates with no HF markup.
- Provider registration requires compatible task APIs, model mappings, billing endpoint and coordination/registration; not casual self-serve worker onboarding.

## Zapier public integrations / Partner Program
- Public integration: https://docs.zapier.com/integrations/publish/public-integration
- Partner Program: https://docs.zapier.com/integrations/publish/partner-program
- Partner benefits: https://docs.zapier.com/integrations/publish/benefits-guide

Established:
- No fee to publish public integration; users pay for their own Zapier plans.
- Partner program benefits focus on distribution, data, support and marketing as integration usage grows.
- This run found no current primary-source basis for classifying ordinary public integrations as a general per-task payout to the integration developer.

## Evidence cautions
- Marketplace publication permission does not grant rights to scrape, copy or resell third-party data.
- “AI agent marketplace” labels are not enough; direct developer/provider payout must be established.
- Integration directories that provide leads/marketing but no payout are distribution channels, not independent income mechanisms.
- Historic monetization announcements must be rechecked against current help/docs before classification.
