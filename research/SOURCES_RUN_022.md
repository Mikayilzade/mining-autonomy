# Sources — Run 022

Evidence date: 2026-08-16

## ThreeFold
- Official farmer manual: https://manual.grid.tf/farmers/intro/
  - Farmers deploy 3Nodes, contribute compute/storage/network capacity, earn rewards for capacity/utilization, and nodes are described as mostly autonomous after setup.
- Official TFT manual: https://manual.grid.tf/labs/documentation/threefold_token/buy_sell_tft/
  - TFT is the ThreeFold Grid token and current official manual documents buy/sell paths.

## ParalonCloud
- Official provider guide, updated 2026-06-08: https://paraloncloud.com/resources/monetize-idle-gpu-passive-income-paralon
  - Docker-based NVIDIA GPU provider model; 80% provider share; per-minute billing; USDC/USDT on Solana; no KYC; no minimum payout; hardware and illustrative listed rates.
- Official platform page: https://paraloncloud.com/
  - Automatic job scheduling/load balancing and provider agent example.
- Official docs: https://paraloncloud.com/docs
  - Provider nodes power inference and rentals; no public IP required for workload tunnel.

## OpenGPU
- Provider onboarding: https://opengpu.network/get-started
  - Provider Suite, automatic routing, completed-task rewards, no OGPU lockup required to provide hardware.
- Provider page: https://opengpu.network/solutions/infrastructure/providers
  - Datacenters, cloud operators, GPU farms, home rigs and edge devices explicitly listed as provider types; automatic workload routing.
- Linux provider app: https://opengpu.network/download/linux
  - Docker Compose deployment and Linux/Docker requirements.
- Protocol: https://opengpu.network/protocol
  - Task-based architecture and provider registration.
- Current investigator: https://investigator.opengpu.network/
  - Current live provider/task surface.

## Iagon
- Compute fees: https://docs.iagon.com/provide-resources/compute-node/compute-fees
  - 90% of monthly compute subscription fees distributed to node providers; weighted by performance and usage.
- Storage fees: https://docs.iagon.com/provide-resources/storage-nodes/fees
  - 90% of storage subscriber fees distributed to storage nodes/delegators.
- Compute rewards/staking: https://docs.iagon.com/provide-resources/compute-node/compute-rewards
  - Capacity-linked IAG staking and three-month retirement/unbonding path.
- Storage staking: https://docs.iagon.com/provide-resources/storage-nodes/iag-staking
  - Capacity-linked staking and retirement logic.
- Storage node FAQ: https://docs.iagon.com/provide-resources/storage-node-setup/faq
  - CLI suitable for remote SSH operation; GUI/CLI function equivalently.

## DeNet
- Official node repository: https://github.com/DeNetPRO/Node
  - Datakeeper server/headless CLI and web manager, storage-user rewards, license requirement.
- Official releases: https://github.com/DeNetPRO/Node/releases
  - Datakeeper Node v4.1.0 released 2026-07-21.
