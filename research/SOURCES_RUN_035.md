## Evidence-quality notes
- Open Cloud and the402 have explicit supplier/provider onboarding language and current payment descriptions; they are materially stronger than branding-only projects.
- ALPENGLOW currently relies heavily on first-party claims; keep WATCHLIST until contracts, operator software and production payouts are independently traceable.
- Cocoon has an explicit GPU-provider flow but requires deeper operator/software/economics validation.
- OpenGradient has strong technical provider architecture but public earning/onboarding economics remain incomplete.
- x402.jobs displays concrete public usage/volume claims; these must be independently validated because raw x402 activity can overstate real external demand.
