# Sources — Run 015

Evidence date: 2026-08-15

## Scam / fraud pattern sources

1. FBI — Cryptocurrency Investment Fraud
   - https://www.fbi.gov/how-we-can-help-you/victim-services/national-crimes-and-victim-resources/cryptocurrency-investment-fraud
   - Supports: fake investment platforms, displayed fake gains, early withdrawals used to build trust, later frozen withdrawals, demands for taxes/fees, recovery scams.

2. FBI — Cryptocurrency Job Scams
   - https://www.fbi.gov/how-we-can-help-you/victim-services/national-crimes-and-victim-resources/cryptocurrency-job-scams
   - Supports: deposit/recharge-to-complete-task fraud pattern; no legitimate job should require depositing own money to perform tasks.

3. CFTC / SEC investor alert — fraudulent digital asset / crypto trading websites
   - https://www.cftc.gov/LearnAndProtect/AdvisoriesAndArticles/watch_out_for_digital_fraud.html
   - Supports: high guaranteed returns, little/no-risk claims, fake proprietary crypto systems/mining farms as fraud red flags.

4. SEC Litigation Release — GA Investors, May 11 2023
   - https://www.sec.gov/enforcement-litigation/litigation-releases/lr-25721
   - Supports: fraudulent mining-pool/investment websites, guaranteed daily returns, initial withdrawals followed by frozen accounts/misappropriation.

5. SEC Litigation Release — CoinW6
   - https://www.sec.gov/enforcement-litigation/litigation-releases/lr-26111
   - Supports: fictitious staking/mining/yield-farming balances and additional tax/fee demands when victims attempted withdrawal.

## Bandwidth / rewards cross-check sources

6. DAWN Terms

7. DAWN Rewards System blog
   - https://www.dawninternet.com/blog-posts/dawn-validator-extension-rewards-system

8. Nodepay — Rewards System
   - https://docs.nodepay.ai/user-participation-and-rewards/rewards-system

9. Nodepay — Utility of $NC
   - https://docs.nodepay.ai/nodecoin-usdnc/utility-of-usdnc

10. Nodepay Privacy Policy

   - Context: Node Points may be earned through unused bandwidth; redemption/value can evolve.

11. Grass — General Terms and Conditions, last modified July 1 2026

12. Grass — Stage 2 Rewards Allocation, July 10 2026

13. Grass — current public FAQ / product page

## Evidence interpretation rules used in this run
- Current official terms/docs override old marketing pages.
- Current redeemable payout path is required before treating points as revenue.
- Docker/Linux availability does not establish server permission.
- A supplier/SDK/fleet program can have different network rules from a consumer application under the same brand.
- Law-enforcement/regulator material is used to define fraud patterns, not to label an uninvestigated named platform fraudulent without platform-specific evidence.
