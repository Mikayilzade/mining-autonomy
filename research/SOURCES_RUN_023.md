# Sources — Run 023

Evidence date: 2026-08-16

Primary/current sources used for provider-tail convergence.

## DCP
- https://dcp.sa/earn — official provider page. Confirms open provider network, 75% provider share / 25% DCP fee, automatic demand routing, detached daemon, successful-work billing, Saudi Riyal settlement, KSA-resident/in-Kingdom positioning, hardware/software requirements.
- https://dcp.sa/docs — official docs. Confirms provider onboarding via `/earn`, setup wizard, signed daemon installer and provider dashboard.

## WorldLand
- https://docs.worldland.foundation/cloud/provider/how-to-provide — official provider setup. Confirms Ubuntu/Docker/Kubernetes provider agent, public IP, provider registration, per-hour billing and 90/10 provider/protocol split.
- https://docs.worldland.foundation/tokenomics/provider-rewards — official provider rewards. Confirms customer-paid compute usage, 90% provider service-fee share, availability/mining reward concepts, and that exact post-testnet reward rates remain unresolved.
- https://docs.worldland.foundation/network/participants — official participant roles. Confirms provider role, 90% rental-fee share, no listed financial requirement for ordinary provider, and idle GPU can also be used for mining.
- https://docs.worldland.foundation/cloud/provider/policy — official provider policy/pricing guidance.
- https://docs.worldland.foundation/introduction/faq — official FAQ, current 2026 documentation.

## StorX
- https://storx.tech/host-node.html — official node-farmer page. Confirms storage contribution, SRX rewards, hardware/network/uptime and staking requirements.
- https://storx.tech/storx-website-host-storage-node.html — official server/VPS setup page. Confirms server/VPS deployment, SRX stake, reputation and passive-storage positioning.
- https://github.com/StorXNetwork/StorX-Node — official node repository. Confirms Docker-based farmer/storage node, staking and slashing warning.

## Abakos
- https://abakos.ai/ — official current product/status page. Confirms public sandbox, provider agent, rental-first + idle mining model, current fee splits, real-USDC sandbox rails, and that mainnet is still planned/gated.
- https://abakos.ai/whitepaper/ — official draft whitepaper. Confirms economics, provider-agent behavior and current implementation status.
- https://abakos.ai/docs/ — official documentation index/status.

## IonDEX
- https://iondex.org/ — official marketplace landing page.
- https://iondex.org/how-iondex-works — official provider/session lifecycle. Confirms provider agent, Windows alpha flow, WSL2/Docker/GPU runtime, provider-set pricing, payout wallet and USDC/Base payment flow.

## CryptoGPU
- https://cryptogpu.com/docs — official provider docs. Claims provider agent, pricing configuration and daemon mode.
- https://cryptogpu.com/marketplace — official marketplace page. Crucially states displayed listings are sample listings and live marketplace data will be available at launch; therefore production provider earning remains unverified.

## ComputeMarket
- https://www.computemarket.tech/ — official landing page. Claims provider agent, automatic job matching, secure container workloads, earnings dashboard and provider payment; insufficient public detail to validate production economics.

## Existing / dedupe confirmations
- https://renderfoundation.com/ — official Render Foundation page; confirms node operators monetize idle GPU compute, but project already existed in catalog.
- https://academy.autonomys.xyz/auto-suite/spaceacres-cli/farmers — official Autonomys farming docs; confirms SSD farming for AI3 rewards, but mechanism is already represented and was not counted as a new top-level category.
