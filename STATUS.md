## Material Run 040 findings

### Inpherio — NEW, strong current candidate
- Live beta peer-to-peer inference marketplace.
- Providers keep 85% of settled usage; 15% platform fee waived for first 3 months.
- Monthly bank payout via Stripe Connect; £10 minimum; £0.50 payout fee.
- Outbound-only provider connector and node rentals support high automation.
- Geography/Azerbaijan eligibility remains unresolved.
- Classification: `VERIFIED / BETA`.

### UsePod — NEW, open inference + authorized API resale
- Providers can run local model-serving agents or relay authorized upstream API capacity.
- Provider receives 80% of settled inference; 20% treasury.
- $50 USDC provider bond; on-demand USDC payout on Solana.
- API-key resale is valid only where upstream ToS/contracts permit resale.
- Geography/KYC/Azerbaijan unresolved.
- Classification: `VERIFIED / RESTRICTED`.

### HZ AI — NEW, live distributed GPU exchange
- Provider installs agent, sets GPU-hour price, jobs are metered per second.
- Fiat payouts through Stripe are explicitly stated.
- Platform fee percentage and geography remain unresolved.
- Classification: `VERIFIED / RESTRICTED`.

### SpotNode.ai — NEW, qualified inference-execution supplier path
- GPU/endpoint owners and infra operators can connect spare capacity through zero-inbound onboarding.
- Supply is benchmarked/qualified before live inference traffic is routed.
- Payout depends on usage and commercial terms; public fee/payout schedule is absent.
- Classification: `VERIFIED / RESTRICTED`.

### KeyMart — NEW, curated enterprise inference market
- Requires identity verification, API-key provenance, upstream-ToS compliance and SLA review.
- Published provider fees: 0% first 7 days; 2.8% standard; 1.6% pro; 0.5% enterprise.
- Self-service withdrawal or scheduled settlement.
- Geography/Azerbaijan unresolved.
- Classification: `VERIFIED / RESTRICTED`.

### Compute Exchange / TCEX — NEW, institutional compute seller channel
- Legal-entity providers can sell professional compute capacity through auction/RFQ/marketplace workflows.
- Current commercial focus is institutional GPU capacity, though terms encompass processing/memory/storage/networking associated with Compute.
- Identity-verified counterparties; current RFQ path is not fully hands-off.
- Classification: `VERIFIED / RESTRICTED`.

### ClusterBid
- Current Terms describe the public site as an early-stage GPU sourcing service; provider commercial engagement is separate.
- Keep `WATCHLIST / RESTRICTED`.

### Exascale / Hyperlink
- First-party site claims a live compute spot/futures exchange with per-second provider payout and T+0 settlement.

## Durable economics findings
- **Paid utilization/fill rate remains the dominant hidden variable.**
- Existing idle-capacity economics and new-hardware CAPEX economics must be modeled separately.
- Transparent provider fee splits do not prove demand.
- Inference-output/token markets are increasingly distinct from raw GPU-hour rental, but economically still monetize compute/model service.
- Authorized API-capacity resale is a real implementation path only when upstream resale rights are explicit.
- Curated enterprise marketplaces can be operationally autonomous after onboarding while still requiring KYB/entity/SLA qualification.
- Azerbaijan remains a hard pre-CAPEX validation gate.
