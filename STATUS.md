## Run 009 — important findings
Physical DePIN was decomposed by the actual paid commodity rather than by the DePIN label.

### Verified physical/device mechanisms
- **Helium IoT/Mobile** — real wireless traffic carriage. IoT gateways can earn HNT for carried LoRaWAN traffic; Mobile/converted Passpoint Wi-Fi can earn for eligible carrier traffic. Important current correction: Helium official docs say Proof-of-Coverage was removed on **2026-07-06**, so old PoC farming assumptions are stale.
- **Hivemapper** — approved camera supplies authentic street-level imagery; HONEY rewards depend on useful/fresh coverage and customer map consumption contributes to token demand/rewards.
- **DIMO vehicle contribution** — a real connected vehicle/integration sends valid telemetry and can receive baseline DIMO rewards; marketplace data access creates a separate demand-side fee pool.
- **GEODNET** — GNSS/RTK base stations receive GEOD; quality, uptime and geographic density affect rewards.
- **WeatherXM** — approved weather station + gateway supplies continuous weather data; current reward mechanism considers data quality, proof of location and cell capacity.
- **Nodle** — smartphone BLE edge node rewards availability/connectivity/geographic coverage; separate publisher SDK is a BUILD-ONCE monetization family.
- **NATIX Drive&** — smartphone/on-device computer vision contributes road-event metadata while genuinely driving.
- **MapMetrics** — global drive/navigation contribution exists, but headline MMAP/hour figures still require liquidity/net-cost validation.

### Watchlist / restricted physical mechanisms
- **Wingbits** — useful ADS-B positional data reward mechanism and approved hardware are documented, but current docs still describe beta/devnet-to-mainnet transition. Do not yet book as proven liquid income.
- **Roam Network** — Android connectivity-measurement network with points and planned XRO conversion; current docs still describe progression toward TGE, so points are not current cash.
- **Silencio** — data monetization/SLC tokenomics exist, but current Terms distinguish in-app Noise-Coins (not cash-redeemable from Silencio) from newer SLC token economics; exact current conversion path needs validation.

### New server-native leads hidden inside physical ecosystems
- **NATIX xNodes** — whitepaper describes staked validator nodes earning from uptime/validation tasks; production public onboarding/hardware/stake/payout still unproven, so WATCHLIST.
- **DIMO Storage Nodes** — DIP economics already allocate a portion of paid data-access demand to storage entities, while current developer docs still mark storage provider as `Coming Soon`; high-value WATCHLIST.
- **DIMO data validators** — current docs still `Coming Soon`; potential future server-native role.
- **Helium multi-gateway server** — one server can front/manage many real IoT gateways. This is a legitimate server control plane, not standalone VPS income because physical radios still create the paid service.
- **Nodle publisher SDK** — app developers can monetize opt-in user-device BLE contribution; BUILD-ONCE rather than server mining.
- **Physical-DePIN fleet orchestration SaaS** — new BUILD-ONCE service family: monitor uptime, firmware, rewards/accounting and deployment health for fleets of earning devices.

### New strategy family
**Compatible physical-DePIN stacking.** Example: Wingbits documents a HYFIX device that can combine Wingbits + GEODNET. Shared hardware/site/power/backhaul can improve unit economics; later profitability work should search for other legal multi-network stacks.

## Durable classification lessons
- Real-world verification (GPS, GNSS, cellular checks, cryptographic hardware, authentic camera/radio/sensor data) defines the commodity. Cloud simulation/spoofing is not an automation strategy and is excluded.
- Docker support on physical hardware does not mean a service can run profitably/legitimately on a cloud VPS.
- Distinguish customer-paid demand from fixed token-emission subsidy and model hybrids separately.
- Points/devnet units/in-app credits are not income until a current redeemable/liquid path is proven.
- A physical network can contain a separate server-native validator/storage/operator role; search infrastructure/developer docs in addition to consumer miner docs.
