## Run 006 important findings
- **Autonomi** is one of the closest current matches to the original low-cost autonomous-daemon concept: official docs explicitly allow headless computers, home servers and virtual environments; nodes use roughly 35 GB storage and earn based on storage/retrieval contribution.
- **TensorDock** still monetizes external hosts but uses vetting and a 99.99% uptime expectation, so it is a real server marketplace rather than a cheap generic VPS bot.
- **Runpod Community Cloud** remains a host/consumer GPU marketplace in current Terms. A new separate BUILD-ONCE mechanism was discovered: Runpod Hub repositories can earn up to 7% of downstream compute revenue as Runpod credits.
- **Render** remains a legitimate paid GPU node role but current onboarding is application/waitlist based and hardware requirements are substantial.
- **ScPrime** still pays storage-provider rent, but broad historical provider incentives ended in Aug 2025 and demand from ScPrime sources requires a license; rent and subsidies must be modeled separately.
- **Arweave** remains a live storage-backed mining role but is not a low-cost VPS opportunity because meaningful operation is storage/system intensive and includes legal exposure from stored data.
