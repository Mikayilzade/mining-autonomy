## Durable strategy model
The machine-paid cluster now has five operational forms:

1. **direct self-hosted paid endpoint** — own API/MCP + payment middleware;
2. **marketplace/proxy monetization layer** — existing endpoint wrapped by a paid relay;
3. **autonomous agent-job marketplace** — structured request/bid/fulfill flows;
4. **build-once paid agent/data/content asset** — skills, packages, datasets, feeds;
5. **demand-signalled production** — create/refresh only when public requests, bounties or usage signals indicate demand.

These are implementation strategies inside the same underlying value source: owned software/data/content/service.
