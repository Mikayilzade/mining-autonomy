## Run 008 important findings
- **Bandwidth monetization must be decomposed by economic mechanism.** Residential proxy exit nodes, authorized datacenter bandwidth suppliers, embedded SDK monetization and proof-of-bandwidth point systems are not interchangeable.
- **EarnFM Fleetshare** is the strongest new server-native discovery in this run. Supplier onboarding accepts 20+ IPs from application users, servers or devices; integration types include Fleetshare server and Docker; authorized datacenter connections have no fixed upper account limit. Current Fleetshare docs list $0.04/GB for datacenter traffic and $0.10/GB for residential, with approval/KYC/KYB/supplier agreement required.
- **EarnApp** remains explicitly residential/personal-device only: VM, Docker, cloud, hosting and servers used for monetization are prohibited, and datacenter IPs are blocked.
- **Honeygain** supports Linux/Docker technically but rejects Data Center IP classes and warns against VPS/VM/emulator usage; treat it as residential for this project. Azerbaijan is present in its current Tipalti payout-country list.
- **PacketStream** currently documents $0.10/GB eligible residential proxy traffic, $5 cashout minimum and a 3% platform cashout fee; demand is not guaranteed.
- **Pawns.app** has Docker/Linux support but current help identifies datacenter-classified IPs as an unsupported/VPN-error condition; no ordinary VPS classification.
- **TraffMonetizer consumer app** explicitly requires residential IP and prohibits server/VPN/proxy use, despite offering Docker. Its separate developer SDK is a legitimate build-once bandwidth monetization model.
- **Repocket** prohibits VPN/proxy/emulator/VM use for ordinary earning.
- **Grass** has current Stage 2 USDC allocation documentation and strongly prioritizes stable residential, non-VPN nodes; traffic/rewards are heavily geography/utilization skewed rather than fixed per connected hour.
- **DAWN Validator Extension** points cannot currently be counted as cash: current Terms say Rewards have no monetary value and are not redeemable/transferable.
- **Nodepay** has shifted toward active predictive-signal participation; current docs emphasize genuine active contribution rather than passive activity, so autonomous engagement botting is not a clean compliant passive-income path.
