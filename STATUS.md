## Economics / risk findings
- **Paid utilization/fill rate remains the dominant hidden variable** across compute, storage, bandwidth, agent and API markets.
- Stablecoin settlement does not prove demand or profit; supplier margin must be modeled after platform fee and upstream/model/server cost.
- Provider bonds/stakes can materially change otherwise low-cost server economics.
- Upstream API resale must be checked against the upstream provider's Terms; a marketplace permitting a relay does not override the API owner's rules.
- First-party dashboards and illustrative screenshots are weaker evidence than distinct paid buyers, attributable settlement and repeated utilization.
- Lack of an explicit Azerbaijan exclusion is not proof of geographic eligibility.
