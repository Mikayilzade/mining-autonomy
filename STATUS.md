## Run 022 durable findings
### ThreeFold Farming
Current official manual confirms farmers deploy 3Nodes that contribute compute, storage and network capacity, earning rewards for available capacity/utilization. Nodes run Zero-OS on standard hardware and are described as mostly autonomous after setup. Classify **VERIFIED/RESTRICTED** pending current farmer reward formula, utilization, TFT liquidity, Azerbaijan path and full CAPEX/electricity economics. This is dedicated-hardware infrastructure rather than an ordinary cheap VPS bot.

### ParalonCloud
Current 2026 official provider material confirms a Docker-based NVIDIA GPU provider agent with automatic scheduling. Official guide states providers receive **80% of rental revenue**, with per-minute billing, USDC/USDT payout on Solana, no KYC and no minimum payout. Classify **VERIFIED/RESTRICTED** pending live utilization, provider security, Azerbaijan onboarding/geofencing and comparative net GPU economics.

### OpenGPU
Provider eligibility is now much clearer: official current pages explicitly list datacenters, cloud operators, GPU farms, home rigs and edge devices. Linux provider software uses Docker Compose; automatic routing assigns workloads; providers earn OGPU for completed tasks; no OGPU lockup is required merely to provide hardware. Current investigator also shows an active provider/task surface. Fiat-equivalent reward normalization remains unresolved.

### Iagon
Current official docs confirm 90% of monthly compute subscription fees go to compute node providers and 90% of storage subscriber fees to storage nodes/delegators. Both roles involve IAG staking; current docs describe a three-month retirement/unbonding path. ROI must therefore include collateral opportunity cost alongside hardware/hosting costs.

### DeNet
Current official repository and v4.1.0 release confirm active server/headless Datakeeper software and storage-user-funded rewards. A Datakeeper license is required. Current license cost, payout/liquidity and realized utilization remain unresolved, so DeNet remains **VERIFIED/RESTRICTED**.

## Durable economics findings
- **Paid utilization, not uptime, is the dominant hidden variable.**
- Owned spare resources structurally outperform retail-cloud re-rental unless the earning market pays an unusual premium.
- Compare net $/GPU-hour, $/CPU-hour, $/TB-month, $/GB and $/IP across opportunities.
- Stake/collateral has opportunity cost, liquidity risk and possible slashing/loss risk.
- Device/license requirements can dominate apparent passive ROI.
- Curated supplier onboarding is common even in decentralized networks.
- Customer-fee allocation is stronger evidence than generic token emissions.
- Explicit provider revenue share (for example Paralon's current 80%) is useful, but paid utilization still determines realized income.
- A current provider software release materially strengthens evidence that an earning path is live.
- Linux compatibility still does not prove every VPS/datacenter host permits the workload.
- Small empirical pilots should precede CAPEX.
