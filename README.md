# mining-autonomy

Research project for mapping autonomous and passive earning opportunities.

Current state: **research in progress**.

Primary question: what legitimate income-producing processes can run continuously online, ideally on servers, with minimal human involvement?

Secondary question: what other passive/semi-passive income systems exist when home hardware, physical devices, capital or a one-time product build are allowed?

Start with [`START_HERE.md`](START_HERE.md). Current state and next step are in [`STATUS.md`](STATUS.md).

No earning strategy in this repository should be treated as profitable merely because it is listed. Candidates are progressively validated for platform rules, economics, risk, geography, KYC and real net return.
